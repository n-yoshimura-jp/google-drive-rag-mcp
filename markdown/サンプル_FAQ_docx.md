**TaskFlow - よくある質問(FAQ)**

**アカウント・料金について**

**Q1. 無料トライアルはありますか?**

はい、14日間の無料トライアルをご用意しています。クレジットカードの登録は不要で、すべての機能を制限なくお試しいただけます。

**Q2. 料金プランにはどのようなものがありますか?**

* **スタータープラン**: 月額980円(5ユーザーまで)
* **ビジネスプラン**: 月額4,980円(20ユーザーまで)
* **エンタープライズプラン**: 月額要相談(無制限)

年間契約の場合、2ヶ月分が無料になります。

**Q3. プランの変更はいつでも可能ですか?**

はい、いつでもプランのアップグレード・ダウングレードが可能です。アップグレードは即座に反映され、ダウングレードは次回の請求日から適用されます。

**Q4. 解約方法を教えてください**

設定メニューの「請求・プラン」から「サブスクリプションをキャンセル」を選択してください。解約後も契約期間の終了日まで利用可能です。

**機能について**

**Q5. モバイルアプリはありますか?**

はい、iOS・Android両方のネイティブアプリをご用意しています。App StoreおよびGoogle Playから無料でダウンロードできます。

**Q6. オフラインでも使用できますか?**

モバイルアプリでは限定的なオフライン機能をサポートしています。オフライン中に行った変更は、オンライン復帰時に自動的に同期されます。

**Q7. 他のツールとの連携は可能ですか?**

以下のツールと連携可能です:

* Slack
* Google Workspace
* Microsoft Teams
* Zoom
* GitHub
* Salesforce

Zapierを使用すれば、5,000以上のアプリとも連携できます。

**Q8. タスクの一括インポートはできますか?**

はい、CSV形式またはExcel形式でタスクの一括インポートが可能です。テンプレートファイルをダウンロードしてご使用ください。

**セキュリティ・データについて**

**Q9. データはどこに保存されますか?**

お客様のデータは、AWS(東京リージョン)の暗号化されたサーバーに保存されます。定期的なバックアップも自動で行われています。

**Q10. データのエクスポートは可能ですか?**

はい、いつでもすべてのデータをJSON、CSV、PDF形式でエクスポートできます。設定メニューの「データエクスポート」からご利用ください。

**Q11. セキュリティ対策について教えてください**

* 通信はすべてSSL/TLS暗号化
* 二要素認証(2FA)対応
* SOC 2 Type II認証取得
* ISO 27001認証取得
* 定期的な脆弱性診断の実施

**Q12. GDPRに準拠していますか?**

はい、GDPR(EU一般データ保護規則)に完全準拠しています。データ処理契約(DPA)の締結も可能です。

**トラブルシューティング**

**Q13. ログインできません**

以下をお試しください:

1. パスワードを再入力(大文字・小文字を確認)
2. ブラウザのキャッシュをクリア
3. 「パスワードを忘れた場合」からリセット
4. 別のブラウザで試す

それでも解決しない場合は、サポートチームまでお問い合わせください。

**Q14. 通知が届きません**

設定メニューの「通知設定」で、通知がオンになっているか確認してください。また、メール通知の場合は迷惑メールフォルダもご確認ください。

**Q15. 画面の読み込みが遅いです**

* ブラウザのキャッシュをクリアしてください
* 使用していないブラウザ拡張機能を無効にしてください
* 大量のタスク(1,000件以上)を表示している場合、フィルターで絞り込んでください

**サポートについて**

**Q16. サポート対応時間は?**

* チャットサポート: 平日9:00-18:00(日本時間)
* メールサポート: 24時間365日受付(返信は24時間以内)
* 電話サポート: エンタープライズプランのみ

**Q17. 導入支援はありますか?**

はい、ビジネスプラン以上のお客様には、オンボーディングセッション(1時間)を無料で提供しています。エンタープライズプランでは専任のカスタマーサクセスマネージャーが付きます。

**Q18. トレーニング資料はありますか?**

ヘルプセンターに動画チュートリアル、PDF資料、ウェビナー録画など豊富な資料をご用意しています。定期的に無料のオンライントレーニングも開催しています。
